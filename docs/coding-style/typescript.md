# TypeScript 開發風格 (TypeScript Coding Style)

適用於 `apps/map/`（Vue 3 · Vite）與 `apps/server/`（Node.js）中的 TypeScript 程式碼。請先讀過 [通用規則](README.md)。

> [!NOTE]
> map 與 server 目前**暫停開發**（見 [`decisions/0008`](../decisions/0008-priority.md)），本文件尚未定義細節，恢復開發時補齊。

## 預定內容

恢復開發時，需要定義以下項目並寫成決策紀錄：

- TypeScript 設定（strict 模式等）
- 命名規則
- lint 與格式化工具
- Vue 元件的寫法（map）
- 錯誤處理與日誌（server）
- 測試框架與命名方式
- 驗證指令
