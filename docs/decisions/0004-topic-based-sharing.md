# 0004. 以主題為單位的分享模型

- 狀態：已採用
- 日期：2026-10-24

## 背景

小隊模式下，使用者希望自己決定要公開什麼，也自己決定要看別人的什麼，而且這兩件事要彼此隔離。

## 決策

- 所有可分享的資料以**主題（topic）**為單位，例如 `position`、`progress.quests`、`progress.hideout`、`keys`、`annotations`
- **發佈端（client）**：每個主題分別設定是否公開；未公開的主題**不會離開使用者的電腦**
- **檢視端（planner／map）**：每個主題分別設定是否顯示隊友公開的資料
- server 只轉發成員選擇公開的主題
- 每個人只能控制自己的追蹤與資料
- 標記（annotations）：房間內任何人都可以新增，只有作者可以刪除

## 理由

- 發佈與訂閱分開，隱私由資料擁有者決定，檢視偏好由觀看者決定
- 新增功能只需要新增主題，分享機制不用改

## 影響

- protocol 的每筆可分享資料都必須標明所屬主題
- 各主題的**預設值尚未定案**（建議：除位置與標記外，其他主題預設不公開），需另行決定後新增決策紀錄
