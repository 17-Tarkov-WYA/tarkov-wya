## 狀態

| 狀態 | 意思 |
|---|---|
| 提議中 | 還在討論，尚未定案 |
| 已採用 | 定案，開發時必須遵守 |
| 已採用（待驗證） | 定案，但依賴尚未驗證的前提，驗證結果可能導致修改 |
| 已取代 | 被新的決策取代（註明取代它的編號） |
| 部分被 NNNN 取代（<被取代的部分>） | 其中一部分被新的決策取代，其餘仍然有效 |

## 新增決策

1. 複製下方範本，建立 `NNNN-<簡短英文說明>.md`，編號接續最後一號
2. 在上方「決策列表」加一行
3. 要推翻既有決策時，**新增一筆**並把舊的標為「已取代」（只推翻一部分時標為「部分被 NNNN 取代」），不要直接改寫舊紀錄

```markdown
# NNNN. <決策標題>

- 狀態：提議中／已採用／已採用（待驗證）／已取代（由 NNNN 取代）／部分被 NNNN 取代（<被取代的部分>）
- 日期：YYYY-MM-DD

## 背景
<為什麼需要做這個決定>

## 決策
<決定了什麼>

## 理由
<為什麼這樣決定、考慮過哪些其他做法>

## 影響
<對開發的具體影響與限制>
```
