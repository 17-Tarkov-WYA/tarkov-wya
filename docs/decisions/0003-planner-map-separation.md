# 0003. planner 與 map 分離，透過 client 串接

- 狀態：已採用
- 日期：2026-10-24

## 背景

工具同時要回答「我進行到哪裡」（任務、物品）與「我在哪裡」（位置）。使用者希望兩者意義分開：可以只用其中一個，也可以一起使用。

## 決策

- **planner**：任務進度、出發前清單、鑰匙管理、藏身處需求；回答「做什麼、帶什麼」
- **map**：自己與隊友的位置、**任務點**、路線與標記；回答「在哪裡」
- **client**：本機中樞，收集所有資料來源（log、截圖座標、手動輸入），提供給 planner 與 map
- planner 與 map **不直接互相依賴**，只透過 client 交換資料
- 一起使用時：planner 把「這場要做的任務」（focus）送到 client，map 只標出相關的任務點

## 理由

- 任務點屬於「位置」，歸 map 才能讓分工清楚
- 透過 client 串接，任一方沒開時另一方照常運作
- 呈現順序為 planner（左，出發前規劃）→ client（中，資料來源）→ map（右，戰局中定位）

## 影響

- planner 不顯示任何地圖或位置資訊
- planner 與 map 之間的資料交換必須定義在 protocol 中
