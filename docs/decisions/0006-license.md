# 0006. 授權採用 PolyForm Noncommercial 1.0.0

- 狀態：已採用
- 日期：2026-10-24

## 背景

本專案僅供研究與學習用途，禁止付費或商業使用，同時希望降低未來被追究責任的風險。

## 決策

採用 [PolyForm Noncommercial 1.0.0](../../LICENSE)。

## 理由

| | MIT | PolyForm Noncommercial |
|---|---|---|
| 商業使用 | 允許 | **禁止** |
| 研究、學習、個人使用 | 允許 | 允許 |
| 免責條款 | 有 | 有 |

MIT 允許任何人販售或做成付費服務，與「禁止付費」衝突。授權無法處理與遊戲公司之間的問題，這部分靠合規原則降低風險（見 [`architecture.md`](../architecture.md) 第 3 節）。

## 影響

- 不得加入任何付費、收費或商業化的功能
- 新增相依套件時，必須確認其授權允許用於非商業專案
- 舊版 repo 以 MIT 公開的程式碼仍適用 MIT；本 repo 為重新撰寫
